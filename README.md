# DaVinci Resolve Interactive Tutorial and Quiz

A self-contained browser tutorial covering DaVinci Resolve's main workspaces, with a knowledge quiz and a workspace-matching exercise.

## Included modules

- Media: importing and managing footage.
- Cut: fast editing and trimming.
- Edit: timeline editing and advanced editing tools.
- Fusion: compositing and visual effects.
- Color: color correction and grading.
- Fairlight: audio editing and mixing.
- Deliver: export workflows.
- Knowledge Quiz: a 12-question interactive review with score feedback.
- Workspace Matching Game: drag-and-drop exercise with a calculated score.

## How to use

Open `index.html` in a modern browser. All HTML, styling, and JavaScript are contained in the same file. No package installation, account, server, or external JavaScript dependency is required.

Choose a module from the navigation at the top. Use the interactive exercises to review material after reading the workspace explanations.

## What this project is

An educational companion and interactive study prototype for DaVinci Resolve. It does not control DaVinci Resolve, process footage, export media, or award an accredited qualification.

## Current limitations

- Quiz and game scoring run locally in browser JavaScript, not in an authenticated assessment system.
- Progress is not saved in browser localStorage; it should not be assumed to survive a reload.
- Tutorials describe application workflows, but version-specific accuracy was not tested against a current DaVinci Resolve installation.
- No automated browser or accessibility tests were run during this documentation update.
